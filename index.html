01 · Definitie

Wat is een voorzetsel?

Een voorzetsel is een klein woord dat de verhouding aangeeft tussen een zelfstandig naamwoord (of voornaamwoord) en de rest van de zin. Het staat bijna altijd vóór een zelfstandig naamwoord — vandaar de naam voor-zetsel.

💡

Geheugensteuntje

"voor" + "zetsel" = een woord dat je vóór een zelfstandig naamwoord zet. Voorbeeld: de kat zit op de mat — op is het voorzetsel dat aangeeft waar de kat zit.

02 · Gebruik

Hoe gebruik je een voorzetsel?

Een voorzetsel staat altijd vóór een zelfstandig naamwoord of voornaamwoord. Samen vormen ze een voorzetselgroep.

Voorzetsel
+
Zelfstandig naamwoord
=
Voorzetselgroep

Voorbeelden:

De kat zit op de tafel.  →  op de tafel = voorzetselgroep
Hij fietst naar school.  →  naar school = voorzetselgroep
We eten om zes uur.  →  om zes uur = voorzetselgroep

Vraagtruc: hoe herken je het?

  • Waar? → plaatsvoorzetsel (in, op, aan…)
  • Waarheen / waarvandaan? → richting (naar, van…)
  • Wanneer / hoe laat? → tijdvoorzetsel (om, na…)
  • Hoe / waarmee? → bijwoordelijk (met, zonder…)

Vaste combinaties

  • denken aan
  • wachten op
  • houden van
  • zorgen voor
  • praten over
  • beginnen met
